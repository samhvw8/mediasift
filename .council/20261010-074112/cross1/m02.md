## Builds
### m02.r1.1 Tiered sidecar whose rungs are the new senses
Builds on: m02.1 + m02.2 + m03.2 + m03.3 + m01.3
The hook-made sidecar (`clip.mp4.fs/`) gets a rung ladder where the cheap rungs are the new perception artifacts, not more keyframes. T0 (seconds, ffprobe + 128x72 pass) writes the slit-scan strip and the labeled spectrogram strip on one shared time axis, because both come from signals framesift already computes. T1 adds motion stills per segment, T2 ASR words printed on the strip, T3 the index. The card names its tier, so a 2 h podcast has a readable strip and "where is the silence" before the first minute is over. Neither parent had this: m03.2 and m01.3 had no schedule, and the ladder had nothing worth showing at T0.

### m02.r1.2 Ask-as-hook: the prompt is the question, so the hook is the budget-setter
Builds on: m02.1 + m03.4 + m03.5 + m01.5
The UserPromptSubmit hook already holds both the video path and the user's sentence. Make the hook pass the sentence to the cheap coarse pass as the question ("why did the build fail" vs "summarize"), so the injected digest spends its fixed token budget around the matching moments and lists the rest in one line each. The agent never types `ask` and never sets `--tokens`: zero knobs, and the budget is a constant in the hook. The sidecar still stores the question-free layers, so the second prompt on the same file reuses them and only re-aims the digest.

### m02.r1.3 Recorder-with-sidecar for the user's own repros, falling back to pixels with the same card shape
Builds on: m02.3 + m01.1 + m03.1 + m03.7
Daily screen recordings are the user's own, so the auto-profile can check for an event sidecar next to the file (clicks, keys, window titles, console errors) written by a one-key recorder wrapper. When it exists, event pairs become before|after images cut at event timestamps with the exact event line as caption. When it does not (a downloaded tutorial), the same card shape is built from pixel-change segments. The agent learns one card format, and the card's first line says "events: exact" or "events: inferred from pixels". That label, which the parents lacked, tells the agent how far to trust cause and effect.

### m02.r1.4 One synthetic-clip bench that doubles as the install self-test and the daily dashboard
Builds on: m02.4 + m02.8 + m01.8 + m03.8
`framesift doctor` renders the 60-line synthetic clips (ball bounces 7 times, beep at 3.2 s, A to B to C UI, 5 s silence) and runs them through the real pipeline with the real dependencies. It passes only if the known answers appear in the card. So doctor tests perception, not just that ffmpeg exists, and a broken llama-server pin or a missing ASR extra fails loudly with one line. The same clips run weekly from the stats log, so a model update that silently hurts counting or audio shows up as a number. The parents' bench measured designs once; this one measures the installed tool every week at no cost.

### m02.r1.5 Push m03.6 to the end: the sound score is the daily podcast product, with chapter stops
Builds on: m03.6 + m02.7 + m02.2
For the 1-2 hour podcast (the case where frames carry nothing), the T0 rung is a pure sound score in text: speech turns with length, silences over 3 s, music or laughter tags, loudness and pace shifts, plus auto-chapters. The card has a hard 1.5k-token budget and a "what I could not tell" footer that names stretches with low ASR confidence. The audio cards are ten times larger in ambition than the parents: every long episode gets a navigable map in under a minute, and Vietnamese or English is detected from the first 20 s without a flag.

### m02.r1.6 Cache you never think about: content-addressed sidecar shared across the Mac and the home GPU box
Builds on: m02.1 + m02.6 + m03.4
The sidecar key is a content hash, and the layers are separate files, so a tier that needs heavy work (large-v3-turbo Vietnamese ASR, a VLM change log) can be filled by the home GPU box when it is awake, over one rsync of a hash-named folder, and is skipped silently-with-a-label when it is not. The Mac never waits and the card says "tier 3 pending on GPU box". YouTube links use the platform captions first. Nothing runs when the box is off, so no daemon exists on either side. The cost it deletes is the 8-minute long-video pass on the laptop.
