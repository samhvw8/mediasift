### m03.r1.1 One redundancy score, one deletion: narration-aware sheets replace the `meaning` captions
Builds on: m03.5 + m03.1 + m02.2 + m01.4 + m01.6
Three members found the same signal (frame vs nearby speech cosine) and used it three ways: demote a frame (m02.2, m01.4), caption it from the transcript (m01.6), drop the VLM (m03.1). Build one score per keyframe with three outputs: high agreement means the cell is demoted and its caption is the retrieved sentence; low agreement means the cell is promoted and is the only kind of frame the harness gets to caption itself. The VLM step is deleted outright, not made rarer, so the one signal removes a metered dependency and a knob. Added: the storyboard prints `says: "..." (cos)` for demoted cells, so the agent can see why an image is missing and ask for it.

### m03.r1.2 The bench ledger: tokens per correct answer, with a random arm and a cheap pre-test per feature
Builds on: m03.8 + m02.6 + m01 provocation (30-minute experiments) + m01.2 + m01.8
m03.8 gives the metric, m02.6 gives the control arm (random frames at equal count and tokens), m01.2 gives gating pre-tests. Join them into one table in `bench/evaluate.py`: rows are features (veto, k-center, narration demotion, medoid, cluster sheets), columns are pre-test result, tokens per correct answer, and delta against random. A feature may be built only after its pre-test passes, and stays only if it beats random; the same run logs mean cosine and drop rate per video (m01.8) so a later commit that shifts them fails the bench. Added: the order of work is decided by the table, and it also prunes: a row that ties random is deleted with its code.

### m03.r1.3 Self-grading sheets: the check loop scored against the bench's own questions
Builds on: m03.4 + m02.1 + m02.7
m03.4 returns the segments an agent summary did not cover; m02.1 audits a caption with cosine. Combine: `framesift check` embeds each sentence of the harness's summary and flags two things, uncovered segments (hole) and sentences near no frame or speech (unsupported claim, the caption audit applied to the agent's own words). m02.7's agreement idea turns it into a confidence label: a sentence backed by two of {frame, speech, audio} is "grounded", one backed by one is "single-source". Added: the bench gets a label-free analysis score (holes plus unsupported claims per summary) that works on any new video, not only the 4 with QA sets.

### m03.r1.4 Ask-conditioned sheets, built at 128 dims with a coverage floor
Builds on: m03.2 + m01.7 + m01.5
m03.2 reorders sheets around a question; m01.7 says run the many-comparison work at 128 dims; m01.5 sizes cells by within-segment spread. Build `--ask` so the question is embedded once at 128 dims, each segment's cell count is spread-sized, and the leftover budget goes to the closest cells, with a fixed floor of one cell per segment so the agent is never blinded outside the question. Added: the floor is the fix for the flaw in goal-conditioned sheets (a wrong question hides the answer), and the 128-dim choice makes a re-ask cost milliseconds, so the agent can ask three questions and get three sheet sets from stored vectors with no re-analysis.

### m03.r1.5 A sheet as a recurring shot, taken ten times further: the whole video as a graph of shots
Builds on: m03.3 + m02.4 + m01.1
m03.3 groups keyframes into one sheet per meaning. Push it: cluster all stored vectors once, name each cluster by its timestamps, and emit a "return map" in the storyboard: A at 0:10, B at 0:40, A at 1:05. The cluster cut-off is set per video by the codec scene-cut split (m02.4), and the ratio of embedding to pixel drift (m01.1) decides per cluster whether it is a screen state or a camera shot, so the same grid carries both. Added: the harness gets the video's structure (what returns, what is one-off) in about ten lines instead of any extra image, and a one-off cluster is by definition the novel material worth an image.

### m03.r1.6 Subtract the audio tower twice: only the speech-gap tags survive
Builds on: m03.7 + m01.3 + m02.5
m03.7 drops the audio tower; m01.3 and m02.5 want it for non-speech stretches. Take out everything but the smallest piece: no audio boundary curve, no open-vocabulary `find --audio`, only the one-line tag on VAD-marked non-speech windows, loaded lazily and only when such a window exists. Added: a trigger that is measurable, not a taste call: the tower loads when the bench video has a non-speech window of at least a few seconds where log-mel changes but no transcript exists, and the rest of the time the 300M weights are never touched.

### m03.r1.7 Fresh: the requirement trace as a bench file, so scope drift is caught by code
Builds on: m03.r1.2 + m03 requirement trace
Reading the others, every idea after this round will again drift toward "better selection". Keep the user's five-part goal (find, grid, send, analyse, extend) as a short checked list in the bench output, each line tied to one number from the ledger: best frames (recall vs random), grids (tokens per correct answer), harness (cells per sheet and total tokens), analysis (holes from `check`). A proposal that moves no line is flagged as outside the ask. Added: scope creep is detected by the bench rather than by memory.
