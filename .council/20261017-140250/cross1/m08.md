## Builds
### m08.r1.1 A read-time header that knows its own age, and fixes it without re-sensing
Builds on: m08.1 + m02.8 + m05.3
All three of us found the dead `framesift look` on 733 cached cards and proposed rendering the header at read time. What this build adds is the cost of staleness in minutes, not just tokens. If `QUAN_REV` or `CED_REV` goes into the cache key, every 47-min talk and 1h45 podcast is silently re-sensed (minutes of MLX, a 3.3 GB peak) the next time any pin moves. Instead, keep the key as it is, store the model revisions in `sensed.json`, and have the read-time header print one line only when they differ: `speech from QUAN rev a1b2 (current c3d4); --fresh re-runs it, ~9 min`. The agent or owner then decides whether the newer model is worth the minutes. Judge: a test that renames the binary, bumps a fake rev, and asserts that the cached card prints no old command and exactly one staleness line.

### m08.r1.2 One speech-integrity marker that makes the card shorter while it makes it more honest
Builds on: m08.3 + m02.2 + m05.6
The ASR loop guard (repeated n-grams), the untranscribed-speech alarm (CED hears speech, ASR wrote little) and the words-per-second gap flag are the same fact: "the speech line here is not what was said". Print them with one shared marker, `say? 02:18-02:31 (speech heard, 5 words written; look)` and `say? 00:41 "bắt tự" x44 (ASR loop)`. The new part is the token budget. Collapsing loops removes more characters (~500 on one real reel) than the gap markers add, so the card gets shorter while it stops hiding errors. Each marker also tells the agent where a `look` is worth paying for. Judge: one synthetic clip with a scripted gap and a forced loop, plus the Tears of Steel official subtitles, scored on precision and recall, with card characters measured before and after.

### m08.r1.3 Captions that agree with speech disappear; only disagreements cost tokens
Builds on: m05.2 + m02.1 + m08.4
On captioned reels the card currently pays twice for the same words: once as `say` and again as OCR `text appeared` fragments. Use m08.4's fuzzy grouping to recognise the caption track, align it to the speech lines (m02.1), and then delete every caption line that agrees with its speech line. Keep only m05.2's token-level disagreements, `"50% [caption: 15%]"`, and one header line, `burned-in captions: 92% agree with speech`. The two-witness check then becomes a token saver rather than an added cost, and the agreement rate is the free real-Vietnamese WER proxy that m02 wanted, printed where the agent can use it to decide how far to trust the speech. 15% start: grep the ~7 real cached cards for OCR lines that overlap `say` lines and count the characters that would be deleted.

### m08.r1.4 Pushed further: the agent stops reading transcripts at all, and asks the cache instead
Builds on: m02.4 + m05.5 + m08.8
m02.4 checks citations after the summary is written. The ten-times version moves that lookup to before and during the writing. `mediasift grep "term" [KEYS...]` searches every cached `sensed.json` (speech, OCR, sounds) and returns only matching lines with cite handles (`3b5f@12:31-12:36 "..."`). `mediasift quote 3b5f@12:31` returns the ±5 s window. The "link these 4 talks" job then becomes a few dozen small lookups instead of four `transcript.txt` reads (m05.5's ~150k tokens). `cite-check` is the same code run over the finished summary. Judge: m05.5's tokens-per-answered-job meter on one real linking job replayed both ways, with the same citations checked by cite-check. Runs: nothing new (local files and deterministic search).

### m08.r1.5 A rent ledger, with today's mood words as the first tenant to pay
Builds on: m08.2 + m02.6 + m05.5
Make the deletion gate a file, `.okf/benchmarks/card-rent.md`: one row per line kind, its share of tokens across the real cards (not the bench cards), and the bench question that justifies it, or "none". The 15% part is that the first column needs only a grep over the 7 real cached cards today, and the mood and genre words get the first row because they are the newest line and have no question yet (m02.6). A line kind whose cell says "none" for two bench rounds moves behind a flag, so lines are evicted by default instead of kept by default. Judge: the ablation on kept rounds (m08.2) plus the owner's 10-clip rating (m02.6) fill the cell.

### m08.r1.6 Price every next step in both meters, failures included
Builds on: m08.5 + m05.7
Image price tags (m08.5) only cover what the agent can open. Failures and fallbacks (m05.7) are where it wastes whole turns. Give every suggested action on the card a price in tokens and minutes: `look 02:18-02:31 (~1.8k tok, ~4 s)`, `--on HOST (~3 min; GPU box unreachable now, local ~9 min)`, and on a failed fetch `not sensed; describing it costs 0 tokens and is wrong; fix: mise up yt-dlp`. The agent can then choose the cheapest path that answers the question, and the owner sees from the header when a job silently became slow. Judge: images opened, `look` calls and wall time per question on the real bench, held at the same score, plus one test per failure path that asserts the priced instruction line is present.
