## Builds
### m06.r2.1 Do both: one cue sheet with two copies, and each column chooses where it lives
Builds on: m06.8 + m01.6 + m08.r1.5 + m01.r1.6
This answers the provocation for the card-versus-file argument. A studio's cue sheet goes out as two copies, a short one for the producer and the full one for the rights desk, and both come from the same rows. mediasift writes the M1..Mn rows once in `sensed.json`. Then it renders two views: the card's cue block for the agent, and `cues.json` for anydub. The new part is that the rent ledger holds two cells per column instead of one per line kind: card tokens against bench questions, and anydub's lag, overrun and broken-invariant counts. A column that pays rent in only one meter lives only in that copy. For example, ducking dB probably goes to the file only and mood words to the card only, so neither reader pays for the other's fields. Judge: m08.r1.5's ablation and m01.r1.6's downstream ablation, run on the same rows.

### m06.r2.2 Clear the hit: the gap map gets a column that says where a dubbed line must not land
Builds on: m07.7 + m07.r1.3 + m06.2 + m01.3
A supervisor tells the dialogue editor "clear the hit": a line must not step on a sting, a button or a downbeat that the edit was cut to. m07.7's gap map tells anydub where a line may stretch. Adding m06.2's ending shapes and the in-music onsets gives each gap a hard edge. Example: `00:42.6-00:44.2 music (scary), button at 00:44.1: stretch to 00:44.0 max`. m01.3's OFF-camera lines may borrow the gap only up to that edge, so an elastic slot never smears the beat that carries the scene. Judge: synthetic clips with scripted stings placed inside the gaps, scored on the count of dubbed lines that overlap a button, before and after, next to anydub's existing overrun metric.

### m06.r2.3 Do both for chapters: slide titles and stings, with agreement printed as confidence
Builds on: m07.8 + m06.2 + m08.7
Talks and podcasts mark sections two ways: a new slide title (m07.8) and an interstitial sting or bed (m06.2). Each misses some cases. A camera-only podcast has no slides, and a lecture often has no music. Run both, because both reuse data that is already computed. Print one `chapters:` line where each boundary carries its witnesses, `12:04 "Memory hierarchy" [slide+sting]` or `31:40 [sting only]`. The same line replaces m08.7's 300-cut list as the long-talk structure. Judge: yt-dlp creator chapters, scored as boundary hits within 10 s for each witness alone and for both. A witness that adds no hits gets cut.

### m06.r2.4 Pushed further: a sound becomes a lead for the fact-check, beyond a credit
Builds on: m01.r1.3 + m06.4 + m07.r1.2
m01.r1.3 matches a bed against the local cache, but the owner's real cache holds about 7 cards, too few to match anything. The version without that flaw starts where TikTok already keeps the answer key. The post's "original sound - @x" (m06.4) is a sound page, and yt-dlp can list the videos posted with that sound. mediasift senses only the audio of the first N (default 5) through the cheap tagger and ASR pass, fingerprints the beds and builds a claims block (m07.r1.2) for each one. The card then gets one line, `sound @x: 5 other reels, 3 make the same claim "[50%] ...", 1 is the earliest (2026-08-02)`. That hands the agent the likely original and the spread of the claim before it searches the web. It is opt-in (`--sound-links`), local, and free per run apart from the downloads. Judge: precision of the fingerprint match against the sound-page labels, plus whether the earliest-post pick matches the poster the owner credits by hand.

### m06.r2.5 Lyrics are neither dialogue nor claims: one source-vs-score label serves the dub and the fact-check
Builds on: m01.2 + m06.6 + m07.r1.2
Rights desks treat a song heard in the scene (radio, phone, busker) differently from score, and for both a sung line is a lyric, not something a person said. Join m06.6's source-or-score usage with CED's singing class and m01.2's keep-list. Each ASR line under a singing bed is then tagged `lyric` once. anydub reads the tag as "keep the original, do not voice it". The claims block reads the same tag as "not a claim", so a chorus saying "100 times better" never reaches web search as a fact to check. One label removes two kinds of noise. Judge: 20 music-backed reels with lyric lines marked by hand, scored on lyric tokens that leak into the claims block and into anydub's dub list, before and after.
