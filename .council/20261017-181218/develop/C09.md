## C09 Check the agent's own deliverable before it says done

## The concept

**Who it is for.** The agent (Claude Code) at the moment it is about to say "done" on media it made or wrote about. Behind it, the owner, who today is the only check: he, or his wife, plays the file and finds the fault.

**The surprise to keep.** The brief asks what the agent cannot perceive in *someone else's* video. The owner's real complaints are about media the agent *made*: "nghe nó rất gấp và bị dính từ" (rushed, words stuck together), "từ 2 nó thành từ 1" (each word's audio shifted by one), "như phim vậy ko phải slide" (film, not slides), "it boken i'm join it". For that media the agent already holds an exact answer key: its own label list, render plan, piece list, or the summary it wrote. So the new sense does not describe the video. It compares the file with the agent's stated intent, and it runs **before** "done", not after a complaint.

**What it is.** One subcommand:

```
mediasift accept TARGET --job tts|clip|join|summary [--intent FILE] [--video FILE|URL]
```

- The **job word picks only the checks that job has failed on before.** No card, no description. Output is a short pass/fail box score, worst items first, at most about 10 lines for a batch of 300 clips. Per-item detail goes to `accept.json` beside the cache.
- Each check has a judge before it ships (the brief's rule). A check that has no measured judge is not in the list.
- **The judge checks itself.** Every run splices known-bad canaries into the batch. If a canary passes, `accept` exits non-zero with "judge broken" and prints no green table. This is "crash rather than corrupt" applied to the checker.

**Evidence that the agent already needs this, from the owner's own disk:**

## How it works

### Shared frame

- **Intent file.** A JSONL sidecar that the generating agent writes (or `accept` builds from a known layout). One line per item: `{"audio": "data/hsk2/tts/b9c4.mp3", "text": "太棒了", "lang": "zh"}`, or a span in a long file: `{"audio": "dist/hsk2/audio/01-1.mp3", "start": 43.87, "end": 44.84, "text": "..."}`. The HSK site needs the span form, because its word clips are spans of textbook tracks.
- **Exit codes.** `0` pass, `1` at least one item failed, `3` judge broken (a canary passed), `2` usage error. A missing model or backend raises one stderr line (existing rule).
- **Token cost.** About 100 to 200 tokens per run. The agent reads `accept.json` only for failed items.
- **Delivery.** One SKILL.md rule: "Before you say done on media you generated, or on a summary with timestamps, run `mediasift accept`." Optional later: a Claude Code Stop hook that adds one line only when the turn wrote `.mp3/.wav/.mp4` files. It costs zero tokens on other turns.

### `--job tts`: heard text, shift, rush, stuck-together

1. **Heard text, independent of the generator.** Transcribe each item **alone**, padded with 0.3 s of silence, with the language forced. Use whisper (mlx-whisper on the Mac, faster-whisper on the box) for zh, because parakeet v3 has no Chinese. Use QUAN for vi and parakeet for en. Do not reuse the generator's alignment. The HSK bug came from whole-track segment timing, so per-item transcription is a different signal path.
2. **Shift by one.** Score heard text of item *i* against labels *i-2 .. i+2*. For zh, compare toneless pinyin (the HSK project already does this with `pypinyin.lazy_pinyin`, so homophone slips still match). For vi, compare syllables with diacritics kept, then without as a fallback. A run of items whose best match is label *i+1* is one fault with one fix: `clips 3-47 match label i+1: shifted by one from clip 3`. Single mismatches are listed as separate items: `clip 112 heard "谢谢观看", label "谢谢"`.
3. **Rushed.** Syllables per second = syllable count from the **label** / voiced duration. Counting is free for zh (one Han character is one syllable) and vi (one space-separated token is one syllable); en uses a pinned syllabifier. Voiced duration = audio minus leading and trailing silence (energy threshold). Reference: Coupé et al. measured read speech at a mean of 6.63 syll/s (SD 1.15) across 17 languages, including Mandarin and Vietnamese. For learner audio, the threshold comes from the human textbook reads in the same project, not from a guess.
4. **Stuck together.** The shortest gap between syllable nuclei, from the energy envelope (intensity peaks with dips between them, the de Jong and Wempe method), plus head and tail silence. ASR word times are **not** used here. QUAN times are 40 ms CTC frames and whisper word times come from attention alignment, both too coarse for a 30 ms gap. Output: `212 clips: 37 joined (gap < 30 ms; textbook median 90 ms), 12 start with no lead-in`. The 30 ms and 90 ms numbers are placeholders until the textbook reads give the real distribution.
5. **Canaries.** For each batch, `accept` takes 3 random passing items and makes known-bad copies: (a) the label swapped with its neighbour's, (b) time-stretched to 1.5x with `ffmpeg atempo`, (c) inner silences removed and the head trimmed. Each must fail its own check. If one passes, exit 3.

Example output:

```
accept tts: 300 items (zh), 3 canaries failed as they must
FAIL shift: clips 3-47 match label i+1 (shifted by one from clip 3)
FAIL rushed: 5 clips over 6.0 syll/s (textbook reads: median 3.9, p95 5.2) - worst b9c4 7.4
FAIL joined: 37 clips with a gap under 30 ms (textbook median 90 ms)
ok   heard text: 252/253 outside the shift run; 1 mismatch (clip 112)
detail: ~/.cache/mediasift/accept/<hash>/accept.json
```

### `--job clip`: render plan diff and motion feel

- **Render plan diff.** The intent lists what should happen when: `{"slide": 4, "start": 12.0, "end": 14.0}`, `{"say": "word 1", "at": 3.2}`. `accept` reuses the cut events from `events.py` and speech cues from `see`: `slide 4 held 0.2 s, intended 2.0 s`.
- **Motion feel, with its cause named.** From the 32x18 grid change series that `see` already computes at 15 fps: (a) the share of change that arrives in one-frame jumps after holds, and (b) exact duplicate frames inside motion runs. The cause decides the fix. Holds while new frames keep arriving point to the animation code: "add easing or tweens". A regular duplicate cadence (for example 1 in 3) points to the encoder: "render fps 20 into a 30 fps file, change the export rate". ffmpeg's `mpdecimate` and `freezedetect` give an independent second reading of duplicates and freezes.

### `--job join`: pieces against the result

- Intent: the piece list. Expected duration = the sum of piece durations, so every join time is known exactly.
- Checks at each join and over the whole file: ffprobe timestamp gaps, frozen picture while audio continues (`freezedetect`), flat audio while the picture moves (`silencedetect`), and a speech line cut mid-word at a join (a cue from `see` that spans a join with a gap inside it).
- Output: `join: 3 pieces, 1:58:10 (pieces sum 1:58:12); picture frozen 41:12-41:50 while audio runs; join 2 cuts the line "...so the next step" mid-word`.

### `--job summary` (also `mediasift verify`)

- **Links land.** Parse every `@12:30`, `[12:30]`, `?t=750` and `&t=12m30s` in the summary. Take the quote or claim on the same line. Match it against the cached transcript (`sensed.json`) within ±5 s. Cue granularity (8 s maximum) is enough, so this needs no new sensing. A miss reports the best match elsewhere: `7/9 links land; @18:02 "AGI by 2030" is at 21:47; @61:10 is past the end (58:40)`.
- **Quotes were heard.** Text in quotation marks must appear in the transcript (normalized token overlap ≥ 0.8), or it is reported as "paraphrase, not a quote".
- **Low-confidence names and numbers (gated).** A quote that holds a name or number heard at low ASR confidence gets a flag: `@18:02 "Karpathy" heard at p=0.31`. This line ships only after the confidence test below passes. The probabilities already exist and are thrown away: faster-whisper `Word.probability`, parakeet-mlx `AlignedToken.confidence`, QUAN's `log_probs` before `argmax`. They go into `sensed.json` only, never into the card.
- **Moments that text cannot find (footer, gated).** `uncited: 03:41 laughter 4.2 s after "...ship on Fridays"; 12:05 most replayed (x2.8 of median)`. Laughter, applause and cheering come from the CED classes `see` already tags. The YouTube "most replayed" heatmap comes from yt-dlp's `heatmap` field, from the same request `see URL` already makes. Today `fetch()` discards it.

Runs: the agent runs `mediasift accept` before it says done; the bench runs as `mise run bench-accept`; nothing runs inside `see`, and the card does not change.

## Prior art (with URLs)

**Close, and what is still different:**

- **ASR round trip for TTS.** NVIDIA Riva's TTS tutorial transcribes synthesized audio and scores CER/WER against the input text: https://docs.nvidia.com/deeplearning/riva/user-guide/docs/tutorials/tts-evaluate.html. Gradium reports TTS quality the same way: https://gradium.ai/blog/word-error-rate-evaluations. A vllm-omni-mlx test plan uses an "ASR round-trip (char-3-gram cosine > 0.9 vs input)" assertion: https://github.com/ThinkFlowLab/vllm-omni-mlx/issues/37. **Different here:** those score each clip against its own text. C09 also matches against neighbours, so a shift shows as one fault with one fix. It also adds envelope rate and gap checks and a canary self-test.
- **Transcription is not enough.** A TTS QC report passed 12 voices with Whisper and waveform checks. 4 still had defects, because Whisper dropped short extra utterances: https://dev.to/orca_forge/defects-missed-in-transcription-ai-speaks-after-05-second-silence-3id5. This supports using the envelope layer for rate, gaps and head and tail silence, and not ASR alone.
- **Broadcast file QC.** Telestream Vidchecker and Interra BATON check delivered files against a spec (loudness, black, freeze) and pass or fail them: https://www.telestream.net/vidchecker/overview.htm, https://www.interrasystems.com/file-based-qc.php. **Different here:** they check a generic tech spec. C09 checks the agent's own intent (labels, slide times, pieces, quotes). It runs locally at $0, and its output is sized for an agent's context.
- **Timestamp errors in LLM video tools.** One project found transcript timestamps past the video's end, including 36,060 s on a 763 s video: https://github.com/dzivkovi/video-intel/issues/139. A paper on video-LLM citations says timestamps "imply grounding without ensuring correctness": https://arxiv.org/abs/2608.15574. LVSum benchmarks timestamp-aware summaries: https://arxiv.org/html/2604.10024v2. **Different here:** C09 checks a finished deliverable against a transcript already on disk, with no model.
- **The owner's own ad-hoc judges.** `check-links.py` and `check-cites.py` in `~/workspace/research/261008-youtube-mind-curation/checks/` check that links resolve and papers exist. They do not check that a moment matches its quote. `accept` replaces judges that are rewritten per job.

**Facts the design rests on:**

- Self-test that fails closed: FIPS 140-3 modules run known-answer self-tests and must enter an error state on failure (NIST implementation guidance): https://csrc.nist.gov/csrc/media/Projects/cryptographic-module-validation-program/documents/fips%20140-3/FIPS%20140-3%20IG.pdf. Vendor example: "the module stops and generates a FIPS error state": https://www.juniper.net/documentation/us/en/software/ccfips22.4/fips-routers-ptx10001-36mr-evo/fips-routers-evo/topics/concept/self-test.html.
- Speech rate: mean 6.63 syll/s (SD 1.15) over 17 languages; speakers range from 4.3 to 9.1 syll/s; one Mandarin character is one syllable (Coupé et al. 2019, Science Advances): https://europepmc.org/article/MED/32047854.
- Syllable nuclei from intensity, without ASR: de Jong and Wempe 2009: https://doi.org/10.3758/brm.41.2.385.
- Duplicate and freeze detection: ffmpeg `mpdecimate`, `decimate`, `freezedetect`: https://ffmpeg.org/ffmpeg-filters.html.
- Confidence values exist in the pinned backends: faster-whisper `Word.probability`: https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py; parakeet-mlx `AlignedToken.confidence`: https://github.com/senstella/parakeet-mlx/blob/master/parakeet_mlx/alignment.py.
- yt-dlp `heatmap` field (start_time, end_time, value 0 to 1): https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/common.py. A third-party guide says "most replayed" shows only on videos without chapters: https://www.tubebuddy.com/blog/youtube-most-replayed/. So the footer falls back to chapters or reactions.
- Speaking rate inside a fixed slot is a known dubbing problem (isochrony): https://arxiv.org/abs/2112.08548.
- TED talks as humor labels: UR-FUNNY: https://arxiv.org/abs/1904.06618.
